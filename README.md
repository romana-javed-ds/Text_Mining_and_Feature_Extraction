# Text Mining and Feature Extraction

## Project Overview
This project demonstrates text mining and feature extraction techniques using Python and a web-page dataset containing 50,000 records and 20 columns.

## Objectives
- Perform text preprocessing and cleaning.
- Remove stop words.
- Apply stemming and lemmatization.
- Implement Bag of Words.
- Extract features using TF-IDF.
- Perform exploratory analysis and visualization.
- Apply Principal Component Analysis (PCA).
- Explore hierarchical clustering.

## Technologies Used
- Python
- Google Colab
- Pandas
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn

## Key Results
- Dataset size: 50,000 records and 20 columns.
- TF-IDF feature matrix: 50,000 × 50.
- PCA: First two components explained approximately 11.05% of variance.
- Hierarchical clustering visualization: 500 documents and 50 terms.

## Project Files
- Jupyter Notebook
- Practical Report
- CSV Results and Visualizations

## Conclusion
This project demonstrates how unstructured text can be cleaned, processed and transformed into numerical features using NLP and machine learning techniques.
